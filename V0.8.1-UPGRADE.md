# Upgrade Guide --- Font Glyph Inspector v0.8.1

**Release:** v0.8.1 --- Variable Font Validation & Interpolation
Analysis\
**Upgrade type:** Additive update. Existing inspection features are
retained.

Panduan ini menjelaskan cara memperbarui project Font Glyph Inspector
dari versi sebelumnya ke v0.8.1 di Windows 11 menggunakan PowerShell.

## 1. Sebelum upgrade

1.  Tutup tab aplikasi Font Glyph Inspector di browser.
2.  Hentikan proses backend dan frontend dengan menekan `Ctrl+C` pada
    masing-masing terminal.
3.  Buat salinan cadangan seluruh folder project yang sedang digunakan.
4.  Ekstrak `font-glyph-inspector-v0.8.1.zip` ke folder sementara.

> Jangan menghapus folder `.git`, `backend/.venv`, atau
> `frontend/node_modules` dari project yang sedang digunakan.
> Folder-folder tersebut tidak perlu diganti saat upgrade.

## 2. Salin file versi baru

Misalnya folder project kamu berada di:

``` powershell
E:\0000 KERJA 3\3 Agus Pexcel\github\font-glyph-inspector
```

Buka folder hasil ekstrak `font-glyph-inspector-v0.8.1`, lalu salin isi
folder tersebut ke folder project yang sudah ada.

-   Izinkan Windows mengganti file yang memiliki nama sama.
-   Pertahankan folder `.git`.
-   Pertahankan `backend/.venv` dan `frontend/node_modules`.
-   Jangan menyalin folder cache Python `__pycache__` jika terlihat di
    arsip.
-   Hapus atau pindahkan `V0.4-UPGRADE.md` dari root project karena
    panduan tersebut hanya berlaku untuk upgrade lama. Simpan salinannya
    di arsip dokumentasi jika masih diperlukan.

## 3. Perbarui dependency backend

Buka PowerShell pada folder project, lalu jalankan:

``` powershell
cd backend
```

Jika virtual environment lama masih tersedia:

``` powershell
.\.venv\Scripts\Activate.ps1
```

Jika folder `.venv` belum ada, buat terlebih dahulu:

``` powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Kemudian perbarui dependency:

``` powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Jalankan pengujian backend:

``` powershell
python -m unittest discover -s tests -v
```

Pastikan seluruh test selesai tanpa kegagalan sebelum menjalankan
aplikasi.

## 4. Perbarui dependency frontend

Buka terminal PowerShell kedua dari folder root project:

``` powershell
cd frontend
npm install
```

Jalankan pemeriksaan build:

``` powershell
npm run build
```

Jika build berhasil, frontend siap dijalankan.

## 5. Jalankan aplikasi

Gunakan dua terminal terpisah.

### Terminal 1 --- Backend API

``` powershell
cd "E:\0000 KERJA 3\3 Agus Pexcel\github\font-glyph-inspector\backend"
.\.venv\Scripts\Activate.ps1
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

API berjalan di:

-   Health check: <http://localhost:8000/api/health>
-   API documentation: <http://localhost:8000/docs>

### Terminal 2 --- Frontend

``` powershell
cd "E:\0000 KERJA 3\3 Agus Pexcel\github\font-glyph-inspector\frontend"
npm run dev
```

Buka alamat berikut di browser:

<http://localhost:5173>

Jika folder project kamu berada di lokasi berbeda, sesuaikan path pada
perintah `cd`.

## 6. Fitur baru v0.8.1

Versi ini menambahkan tab **VF Validation** untuk pemeriksaan Variable
Font.

Pemeriksaan yang tersedia:

-   Rentang axis dan koordinat default `fvar`.
-   Tag axis dan koordinat named instance.
-   Pemetaan koordinat `avar`.
-   Referensi axis pada `STAT`.
-   Pembuatan static instance nyata menggunakan FontTools
    `varLib.instancer`.
-   Pengujian pada default, endpoint axis, named instances, dan sejumlah
    kombinasi multi-axis yang representatif.
-   Pemeriksaan referensi glyph/komponen serta horizontal metrics pada
    instance hasil.

Endpoint API baru:

``` text
GET /api/fonts/{font_id}/variable-validation
```

Fitur v0.8.0 **Variable Font Lab / Inspector** tetap tersedia.
Pemeriksaan bersifat read-only dan tidak mengubah atau mengekspor ulang
file font sumber.

## 7. Catatan performa dan batasan validasi

Pengujian multi-location dapat memerlukan CPU dan RAM yang cukup besar,
terutama pada font dengan jumlah glyph banyak atau banyak axis. Waktu
proses bergantung pada kompleksitas font dan perangkat yang digunakan.

Hasil `Passed` berarti instance berhasil dibuat dan pemeriksaan
struktural yang diterapkan berhasil. Hasil tersebut **bukan
sertifikasi** bahwa interpolasi visual selalu mulus atau sesuai dengan
maksud desain pembuat font.

Pemeriksaan ini menguji sejumlah lokasi representatif, bukan seluruh
kemungkinan koordinat dalam ruang desain. Perubahan bentuk yang tidak
diinginkan, kink, atau inkonsistensi visual tetap perlu ditinjau dengan
specimen dan pemeriksaan desainer.

## 8. Jika aplikasi tidak berjalan

-   Pastikan backend aktif pada port `8000`.
-   Pastikan frontend aktif pada port `5173`.
-   Periksa apakah virtual environment backend sudah aktif sebelum
    menjalankan Uvicorn.
-   Jika dependency berubah atau instalasi bermasalah, jalankan kembali
    `python -m pip install -r requirements.txt` dan `npm install`.
-   Jika port sedang digunakan aplikasi lain, hentikan proses yang
    memakai port tersebut atau atur port secara konsisten pada
    konfigurasi frontend dan backend.
